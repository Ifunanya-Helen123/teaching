**How to run it**: 
1. Open terminal (type : git --version) to check whether you have git installed already on your pc and the git version
===


2. If otherwise, download and install it.
===


3. Go to github to fork repo as instructed by Oga Boiz

4. Copy the forked repo link

5. On your terminal, Type :git clone space https://github.com/ogungbemichael/teaching.git (to clone the repo to your local)

6.Then clone is complete

7. On the folder you selected, open teaching folder>README.md and edit

8. You are done
